# 賓客名單匯入

目前支援從 RSVP 匯出的七欄 CSV 產生新版 `Guests` 五欄格式。這個流程以一列代表一位主要聯絡人／主要送禮人，不拆分同行者。

## 來源格式

來源第一列必須包含下列欄位，順序可以不同：

```text
Name,人數,分類,喜餅,確認,素食,備註
```

欄位對照：

| RSVP 欄位 | Guests 欄位 | 規則 |
| --- | --- | --- |
| `Name` | `顯示姓名` | 必填，前後空白會移除 |
| `分類` | `新郎/新娘方` | 必填，保留完整分類，例如共同朋友、女方媽媽同事 |
| `備註` | `備註` | 保留原備註 |
| 無 | `賓客ID` | 預覽階段留白；最終名單確認後再配置 |
| 無 | `桌號` | 留白，可直接在 Sheet 補填 |

`人數`、`喜餅`、`確認`、`素食` 不匯入 `Guests`。轉換時排除 `確認` 明確等於「不參加」的資料；空白或「！待回復！」仍先保留，等最終名單確認後再決定是否移除。

## 顯示姓名原則

建議使用「本名（常用稱呼）」而不是只放綽號，例如 `王小明（阿明）`。收禮金人員可以用本名核對紅包署名，你們也能用綽號搜尋。系統的姓名查找支援部分文字，不需要另加綽號欄位。

家庭或親戚稱呼也建議把主要聯絡人的本名放前面，例如 `陳美玲（大阿姨家）`。如果暫時不知道本名，可以先保留現有稱呼，最終名單確定時再補，不要由轉換工具猜測姓名。

## 產生匯入檔

在專案根目錄執行：

```powershell
node scripts/prepare-guest-import.mjs "來源名單.csv" "outputs/guest-import/Guests.csv"
```

輸出 CSV 固定為：

```text
賓客ID,顯示姓名,新郎/新娘方,桌號,備註
```

工具會排除明確不參加者，驗證其餘資料的必要欄位、空白姓名與空白分類，保留逗號或換行等合法備註，並避免文字被試算表當成公式執行。輸出使用 UTF-8 BOM，方便 Excel 與 Google Sheets 正確顯示中文。

## 正式匯入前

目前產物只供預覽與整理，不直接覆蓋正式 `Guests`。名單尚未定稿時不要固定 QR 編號。

最終匯入時需要先：

1. 備份 `Guests` 與 `Gifts`。
2. 確認哪些既有賓客 ID 已被 Gifts 引用，這些 ID 不可改配給別人。
3. 對照舊 Guests 保留既有 ID，只讓真正新增且仍空白的資料執行 `generateGuestIds`。
4. 補齊桌號後重新登入手機，下載最新名單快照。

不要直接把 RSVP 七欄 CSV 貼到 `Guests`，否則欄位會錯位。
