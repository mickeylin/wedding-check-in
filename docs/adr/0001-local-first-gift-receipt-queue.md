# 禮金收件先保存裝置再背景同步

Apps Script 每次往返約有一至兩秒平台等待，搬到 HtmlService 實測只縮短約 0.30 秒。為讓工作人員立即處理下一位並涵蓋一般斷網，禮金收件先以唯一請求編號安全保存在操作手機，再背景同步到 Google Sheet；只有本機保存成功才顯示可繼續，Sheet 回覆撞單則進入待核對而不默認成功。這增加了待同步狀態與裝置端資料管理，但保留後端鎖及請求冪等作為兩支手機的最終一致性保護。

已由使用者操作驗證的狀態模型原型保留於 `codex/offline-gift-queue-prototype` 分支的 `f2c3977`。
