# 接待介面審視與調整

## 現場任務

工作人員需要迅速確認賓客、告知桌號、登記實體紅包並處理下一位。登入及下載名單是準備作業；同步核對是持續可見的輔助作業。

| 問題 | 調整 |
| --- | --- |
| 設定長期佔據手機頁首 | 登入成功自動收合，頁首顯示登入人員，保留更新名單入口 |
| 未啟動相機也佔用大片黑色區域 | 啟動時展開，停止或啟動失敗後隱藏 |
| 掃描、查找與結果散落三欄 | 桌面兩欄查找，手機單欄，賓客結果只有一張卡 |
| 姓名、桌號、編號和說明同樣大小 | 姓名及桌號、編號放大，狀態與操作說明分層 |
| 同一結果在下方與彈窗重複出現 | 下方獨立結果區移除，登入／查詢進度用上方狀態提示 |
| 下一位與收件按鈕容易混淆 | 收件為主按鈕，未收件時下一位明示「只查桌號」；撤銷保留確認 |
| 耗時資訊插在動作前面 | 移至動作之後並收合 |
| 完成紀錄搶走注意力 | 紀錄預設收合，同步摘要常駐，待核對自動展開 |
| 鍵盤焦點可跑到彈窗後方 | 結果開啟時背景 inert、Tab 限制在結果內、Escape 等同下一位，忙碌時無法離開 |
| 背景同步更新打斷目前焦點 | 已開啟結果更新時不重新搶焦點 |

結果卡仍採對話框：同一時間只處理一位賓客，與掃描防重複閘門一致。手機靠下呈現方便按動作，桌面置中；長內容可在卡內捲動。

## 驗證與限制

已加入工作表遷移、主檔備註保留及登入／結果狀態的自動測試。瀏覽器安全政策阻擋本機 file URL，因此未完成實機視覺驗收，不能將程式測試當成手機操作驗收。

部署後請以兩支實際手機確認：首次登入與重開分頁、設定收合、更新名單、掃描／手動／姓名查找、僅查桌號、收件後下一位、背景同步、待核對、相機拒絕權限、離線、長姓名、未分配桌號，以及鍵盤不遮擋主要操作。
